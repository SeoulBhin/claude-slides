# 고객센터 FAQ 챗봇 1차 도입 기획 (초안)

작성: 김지원(고객지원팀) / 2026-11-06

## 왜 하나
- 최근 4주 문의 2,312건 중 41%가 FAQ에 이미 답이 있는 질문(결제 실패, 비밀번호 재설정, 영수증 발급)
- 상담원 4명이 같은 답을 반복하느라 복잡한 문의 첫응답이 늦어짐 (평균 37분)
- 야간(18시~09시) 문의는 다음날 아침까지 답이 없음

## 무엇을 하나
- 웹 고객센터 화면에 FAQ 챗봇을 붙인다. 답은 기존 FAQ 문서 안에서만 한다
- 챗봇이 못 풀면 "상담원 연결" 버튼 → 기존 티켓으로 넘어감 (대화 내용 첨부)
- 결제·환불처럼 계정 정보가 필요한 건 챗봇이 처리하지 않고 바로 상담원으로

## 하지 않는 것 (1차 범위 밖)
- 카카오톡 채널 연동
- 환불 자동 처리

## 일정 (6주)
1~2주: FAQ 문서 정리, 질문 유형 분류
3~4주: 챗봇 연결, 사내 테스트
5주: 고객 20% 대상 시범 운영
6주: 결과 보고, 전체 적용 여부 결정

## 목표 숫자
- FAQ 유형 문의 중 챗봇 해결률 60%
- 상담원 첫응답 평균 37분 -> 25분
- 챗봇 답변 만족도(좋아요 비율) 70% 이상

## 비용
- 챗봇 도구 월 구독 45만원, 초기 설정 외주 없음(내부 진행)

## 리스크
- FAQ에 없는 걸 지어내서 답할 수 있음 -> FAQ 문서 밖 답변 금지 설정, 시범 기간 대화 로그 매일 검토
- 고객이 챗봇을 싫어할 수 있음 -> 첫 화면에 상담원 연결 버튼 항상 노출
